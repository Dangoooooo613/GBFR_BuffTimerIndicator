== v20.65 ==
- 修复打开设置时的崩溃 bug「cannot access free variable 'QLabel' where it is not associated with a value in enclosing scope」。
  原因：「过滤垃圾」tab 的构建方法内多写了两行 `from PySide6.QtWidgets import QPlainTextEdit, QLabel` 和 `from PySide6.QtWidgets import QDoubleSpinBox`，

- User screenshots reported two rendering bugs still in `_draw_spikes` after the V2034 split; rewrite of that function fixed both:

== v20.25 ==
- **Fixed "auto-hide when game loses focus" wrongly treating click/drag/resize of the overlay's own modules as "game in background"**: clicking or dragging a module made the whole window vanish, so users couldn't adjust module size/position/scale at all. Root cause: `_game_is_foreground()` only accepted the game PID (`self.pid` holds the game process), so when a user clicked/dragged a module the foreground became the tool's own process (not in the set) and was judged "background" -> hidden. == v20.24 ==
- **Fixed overlay text rendering as tofu boxes (□□) on Windows regional settings = "Hong Kong (Traditional Chinese)"**: A user reported "boxes appear when region is Hong Kong, switching back to mainland fixes it". Root cause: Qt on Windows does not read the system's Asian-font fallback table, and the entire codebase has 21 hardcoded `QFont("Segoe UI", ...)` calls -- Segoe UI contains no CJK glyphs so Qt falls back to the missing-glyph rectangle. V2024 scans `QFontDatabase.families()` at startup (in `main()`), picks an installed CJK family by priority (Microsoft YaHei -> JhengHei -> PingFang SC -> SimHei -> Malgun Gothic -> Yu Gothic -> Meiryo -> Source Han Sans CN/TC -> Noto Sans CJK), and calls `QFont.insertSubstitution("Segoe UI", cjk_family)` so every `QFont("Segoe UI", ...)` request that hits a missing glyph is filled by the CJK family -- zero call-site changes.
- Version +1 (V2023 -> V2024, title bar reports 20.24), schema 94 unchanged.
